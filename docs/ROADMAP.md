# Roadmap

Roadmap 表示方向，不是发布承诺。优先级会根据 Issue、维护成本和贡献情况调整。

## 近期

- 设置页的 LLM 连接测试和 Provider 能力元数据。
- 数据库显式 schema version、非破坏性迁移和备份/恢复命令。
- 前端关键流程的自动化测试。
- 任务导入/导出为可迁移项目包。
- 降低 PDF 导出依赖的前端包体。

## 中期

- Whisper 模型管理、硬件检测和性能预估。
- MinerU/OCR PDF 结构化解析，作为明确的可选组件。
- Provider 插件发现机制，减少前后端重复注册。
- Obsidian/普通 Markdown Vault 导出。
- 可选的本地认证，服务于 NAS 和可信局域网部署。

## 暂不计划

- 默认公网 SaaS 部署。
- 多租户、计费和云端用户系统。
- 绕过视频平台权限、版权或风控限制的功能。
