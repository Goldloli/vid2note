## ADDED Requirements

### Requirement: 六个主页面具有统一的页面层级

主控台、笔记、思维导图、历史、ASR 和设置 MUST 使用统一的视觉 token、页面头、内容分区、操作层级和状态反馈。每个主页面 MUST 在主内容区开头提供可识别的页面标题与用途说明；页面级主操作 MUST 与局部分区操作在位置和视觉权重上可区分。

#### Scenario: 六个页面的页面头和主操作层级一致

- **WHEN** 用户依次访问六个全局导航页面
- **THEN** 每页 MUST 显示统一结构的页面标题与用途说明，存在页面级主操作时 MUST 位于一致的操作区域，页面 MUST NOT 以无标题的卡片或工具栏直接开场

#### Scenario: 页面分区使用统一视觉语言

- **WHEN** 页面同时包含多个内容分区
- **THEN** 分区 MUST 使用一致的表面、边界、间距和标题层级，按钮、输入、状态徽章与空状态 MUST 复用统一 token，亮暗主题下 MUST 保持清晰可读

### Requirement: 应用骨架适配桌面与平板窗口

应用骨架 MUST 在宽桌面、小桌面和不窄于 768px 的平板/小窗口下提供可用导航与主内容布局。窗口变窄时侧栏 MAY 压缩为图标轨道或可展开导航，但全部六个导航入口、当前页状态和关键全局状态 MUST 仍可访问；主内容 MUST NOT 被导航遮挡或产生完成主要任务所必需的页面级横向滚动。

#### Scenario: 宽桌面显示完整侧栏

- **WHEN** 视口宽度不小于 1180px
- **THEN** 应用 MUST 显示带文字的完整侧栏、当前页激活态和引擎状态区，主内容 MUST 使用与页面类型匹配的标准或工作区宽度

#### Scenario: 小桌面压缩导航但保留可识别性

- **WHEN** 视口宽度介于 900px 与 1179px
- **THEN** 应用 MAY 将侧栏压缩为图标轨道，但每个入口 MUST 具有可访问名称或可见提示，当前页 MUST 仍可区分，内容区 MUST 获得足够可用宽度

#### Scenario: 平板窗口可展开全部导航

- **WHEN** 视口宽度介于 768px 与 899px
- **THEN** 应用 MUST 提供紧凑且可展开的导航方式，用户 MUST 能到达全部六个页面，导航层关闭后 MUST NOT 遮挡主内容或遗留滚动锁定

### Requirement: 主控台按任务优先级组织信息

主控台 MUST 将新建任务作为首要内容，将网络来源与本地来源作为同等入口，并将常用任务参数与低频高级参数分层呈现。运行任务、统计概览和最近完成内容 MUST 按当前任务状态形成清晰优先级；无运行任务时 MUST 显示有下一步提示的空状态，不得仅保留大块空白。

#### Scenario: 新建任务与常用参数首屏可见

- **WHEN** 用户在桌面窗口打开主控台
- **THEN** 网络来源、本地来源、ASR、LLM、输出语言和开始操作 MUST 在无需寻找隐藏菜单的情况下可到达，低频参数 MAY 收入明确标注的高级选项

#### Scenario: 任务级 LLM 只展示已配置厂商

- **WHEN** 后台设置响应包含多个注册厂商，但其中部分厂商缺少必需凭证、模型或 Base URL
- **THEN** 主控台 LLM 下拉框 MUST 只展示满足后台公开配置状态的厂商，MUST NOT 展示未配置厂商或读取凭证明文；当前默认厂商不可用时 MUST 回落到第一个已配置厂商，没有任何可用厂商时 MUST 禁用任务提交并提供前往设置的入口

#### Scenario: 存在运行任务时优先展示进度

- **WHEN** 主控台存在一个或多个运行中任务
- **THEN** 运行任务分区 MUST 在视觉上优先于最近完成内容，每个任务 MUST 继续展示流水线、百分比、状态和详情入口

#### Scenario: 无运行任务时提供有意义空状态

- **WHEN** 运行任务列表为空
- **THEN** 页面 MUST 显示当前没有运行任务及如何开始的提示，MUST NOT 只显示空白区域或孤立数字零

### Requirement: 笔记与思维导图采用统一资料库工作区

笔记和思维导图全量浏览页 MUST 使用统一的资料库工作区信息架构，包含可搜索任务列表、主要内容区和上下文/操作区。进入页面时 MUST 默认选中最新可用任务；选中其他任务后主要内容与上下文区 MUST 同步更新。宽度不足时次要区域 MUST 可折叠或切换，主要阅读或画布区域 MUST 保持优先。

#### Scenario: 默认选择最新资料

- **WHEN** 用户从全局导航进入 `/notes` 或 `/mindmaps` 且存在已完成任务
- **THEN** 资料列表 MUST 选中最新可用任务，主要内容与上下文区 MUST 展示同一任务的数据

#### Scenario: 搜索和切换资料

- **WHEN** 用户在资料列表搜索并选择另一条任务
- **THEN** 列表 MUST 清晰标记新选中项，主要内容、标题、大纲和操作 MUST 同步切换到该任务，MUST NOT 残留前一任务的内容或状态

#### Scenario: 正文挂载后生成章节大纲

- **WHEN** 所选笔记加载完成且净化后的正文包含 Markdown 标题
- **THEN** 资料库页和单篇笔记页 MUST 在正文 DOM 挂载后生成非空章节大纲，点击章节 MUST 滚动到对应标题；切换资料、加载失败或正文不含标题时 MUST 清理上一条笔记的大纲和观察状态

#### Scenario: 小桌面收起次要上下文区

- **WHEN** 资料库工作区宽度不足以舒适容纳三栏
- **THEN** 主要阅读或画布区域 MUST 保持可用，资料列表和上下文区 MUST 通过明确控件折叠、展开或切换，关键导出与查看操作 MUST 仍可到达

#### Scenario: 资料为空或加载失败

- **WHEN** 没有可用笔记/导图或请求失败
- **THEN** 工作区 MUST 显示统一空状态或错误状态及下一步/重试入口，MUST NOT 以空白主面板或单个破折号作为唯一反馈

### Requirement: 历史页提供自适应的数据浏览体验

历史页 MUST 在桌面端保留高效的数据表格，并将搜索、状态、来源筛选、批量操作和分页组织成清晰层级。窄屏/平板环境下 MUST 使用无需页面级横向滚动即可完成主要操作的自适应任务列表，且不得丢失选择、状态、来源、时间、产物入口或失败重跑能力。

#### Scenario: 桌面端表格层级清晰

- **WHEN** 用户在宽度不小于 900px 的窗口打开历史页
- **THEN** 页面 MUST 显示桌面数据表格，筛选工具栏、行选择、状态、来源、时间、产物操作和分页 MUST 对齐且易于扫描

#### Scenario: 窄屏切换为任务卡片

- **WHEN** 用户在 768px 至 899px 的窗口打开历史页
- **THEN** 历史记录 MUST 以自适应卡片或等价单列结构呈现，用户无需页面级横向滚动即可查看状态、来源、时间并执行产物查看或重跑

#### Scenario: 批量操作仅在存在选择时突出

- **WHEN** 用户选择一条或多条历史记录
- **THEN** 页面 MUST 显示包含选中数量和批量动作的明确操作区；清空选择后该操作区 MUST 收起或恢复为非强调状态

### Requirement: 异步状态与操作反馈跨页面一致

依赖异步数据的主页面 MUST 明确区分首次加载、空数据、请求失败和已加载状态。首次加载 MUST 使用与目标布局接近的骨架或加载状态；失败 MUST 提供可理解的错误说明和可行时的重试入口；保存、测试、复制等短操作 MUST 通过统一反馈确认结果。

#### Scenario: 首次加载不显示错误空白

- **WHEN** 页面正在等待首次 API 响应
- **THEN** 页面 MUST 显示稳定的加载状态，MUST NOT 暂时渲染为“没有数据”、单个破折号或完全空白

#### Scenario: 请求失败允许重试

- **WHEN** 页面核心数据请求失败且该请求可重试
- **THEN** 页面 MUST 显示错误状态和重试操作，重试 MUST 再次发起对应请求且不要求刷新整个应用

#### Scenario: 短操作给出非阻塞反馈

- **WHEN** 保存设置、测试连接、复制内容或触发导出成功或失败
- **THEN** 页面 MUST 使用统一 Toast、内联结果或等价非阻塞方式反馈结果，不得仅依赖控制台日志

### Requirement: 主题、焦点和动态效果保持可访问

所有新增或重构界面 MUST 同时支持亮色与暗色主题。图标按钮 MUST 提供可访问名称；键盘可操作控件 MUST 具有清晰 focus 状态；激活、成功、警告和失败状态 MUST NOT 只依赖颜色传达。非必要动画 MUST 在用户偏好减少动态效果时关闭或显著缩短。

#### Scenario: 暗色主题保持内容层级

- **WHEN** 用户切换到暗色主题并访问六个主页面
- **THEN** 页面背景、表面、边框、正文、辅助文字、状态和 focus MUST 保持足够区分，MUST NOT 出现仅为亮色主题硬编码而不可读的区域

#### Scenario: 键盘与图标按钮可识别

- **WHEN** 用户使用键盘遍历导航、工具栏、筛选和页面主操作
- **THEN** 当前焦点 MUST 始终可见，纯图标按钮 MUST 暴露可访问名称，压缩导航项 MUST NOT 只通过无文本图形表达用途

#### Scenario: 减少动态效果偏好生效

- **WHEN** 浏览器启用 `prefers-reduced-motion: reduce`
- **THEN** 背景移动、进入动画、脉冲和非必要平滑过渡 MUST 被关闭或显著缩短，功能状态变化 MUST 仍清晰可见
