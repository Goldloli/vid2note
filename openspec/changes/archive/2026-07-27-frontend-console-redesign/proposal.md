## Why

主控台当前「本地视频/音频上传」是网络视频输入框下面的一个小按钮，地位弱；且**选文件后自动提交开始**（无法先选好 ASR/LLM 引擎再开始）。需重组：**网络视频与本地文件两个并列、同等重要的区域**；选 URL / 文件后**不自动开始**，手动点「开始」才提交。

## What Changes

- 「新建任务」区改为**两区并列**：
  - **网络视频**：URL 输入框（粘贴 YouTube/Bilibili/直链）
  - **本地文件**：文件选择区（点击/拖拽选 video/audio，显示已选文件名）
- **引擎选择（ASR / LLM / 语言 / 截图）共享**，放在两区下方一行（两区共用）。
- **不自动开始**：选文件只暂存（不提交），点「开始」才创建任务。
- 「开始」按钮智能提交：URL 非空 → 用 URL；否则若已选文件 → 用文件；都没有 → 提示。

## Capabilities

### New Capabilities

（无。）

### Modified Capabilities

- `web-frontend`：修订「主控台任务创建入口」——网络视频与本地文件两区并列；本地文件选择后 MUST NOT 自动开始，MUST 等用户点「开始」。

## Impact

- **前端**：`Console.vue` 重构（两区 + 手动开始逻辑）。
- **spec**：`web-frontend` MODIFIED 主控台任务创建入口。
- **测试**：`npm run build`；手动验证两区 + 手动开始。

## Non-goals

- 引擎选择项内容不变（ASR/LLM/语言/截图 原样，只是布局下移共享）。
- 统计卡 / 进行中列表 / 最近完成表格 不变。
- 不引入拖拽上传（v1 用文件选择对话框；拖拽留后续）。
