# vid2note v1 实现任务清单

> 变更:`build-vid2note-v1`。按六步流水线阶段分组(项目骨架 / 下载 / ASR / 笔记 / 导图 / PDF / 前端 / 设置 / Docker)。
> 每个任务末尾括注独立验证方式。基底 = fork 自 ai_srt2md,内核(LLM 适配 / prompt 库 / SRT→笔记 / 注入防护 / 思维导图导出 / SQLite)原样复用。
