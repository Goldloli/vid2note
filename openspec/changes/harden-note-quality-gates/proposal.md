## Why

四档真实长视频笔记审阅表明，当前适中档已经清晰可用，但详细与超详细会把 ASR 错词、数字/单位矛盾、语义重复和课程边角内容随篇幅一起放大，导致“覆盖更多”却不一定“更可靠”。现在需要把质量控制从结构正确提升到事实一致、信息密度和复盘可用，优先使用本地确定性门禁，避免用更多付费重写掩盖问题。

## What Changes

- 为内容地图和终稿增加数字、单位、比例及简单算术一致性检查；冲突只进入对应章节的定向修复，不全篇重写。
- 识别连续重复词、同词括注、低置信专名/缩写和明显 ASR 残词；能确定时机械清理，不能确定时要求保留“不确定”表达而非猜测。
- 在章节蓝图阶段按章节目的与证据集合执行语义近重复门禁，避免详细/超详细重复展开同一论证。
- 将寒暄、下期预告、会员/个人事务等行政与边角内容从核心笔记排除；只有与课程目标直接相关的行动项可保留。
- 调整详细档为约 42 条证据、每批最多 3 章、风险触发语义审计；数字一致性与结构门禁仍固定执行，以降低调用和审计放大。
- 适中档保留现有覆盖和成本配置，并强化开头结论/行动摘要、观点归因与不确定实体表达。
- 扩充单元与集成测试并执行后端、前端和 OpenSpec 全量回归。

## Non-goals

- 不修改 ASR 引擎、下载、截图、思维导图、任务 API 或前端视觉。
- 不接入外部事实核验、搜索引擎、数学模型或新依赖；只校验字幕证据与终稿的内部一致性。
- 不承诺自动纠正所有音译专名；证据不足时宁可标注不确定，也不生成看似正确但无依据的实体。
- 不在本变更中发起新的付费真实视频任务；先用已保存的真实失败样例和 mock LLM 完成确定性回归。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `note-generation`: 增加数字/单位一致性、低置信术语、语义去重和核心内容相关性门禁，并调整详细档成本策略。

## Impact

- 后端主要影响 `src/core/simple_processor.py`、`src/prompts/detail_level.py` 与 `tests/test_note_detail.py`。
- 复用 ai_srt2md 现有字幕解析、注入防护、提示词清洗、PDF 参考和 Markdown 组装能力；新增质量元数据、确定性校验与局部修复路由。
- API、数据库任务快照和历史产物格式保持兼容；无需新增依赖或数据迁移。
