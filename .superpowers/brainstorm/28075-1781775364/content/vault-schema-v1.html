不可变层

raw/ 只追加、不修改。视频、SRT、来源身份和内容哈希共同构成审计基础。

来源层

sources/ 保存单一视频的高质量结构化笔记，事实必须带时间码引用。

综合层

wiki/ 不按视频组织，而按概念、实体和主题组织；同一页面可综合多个来源。

缓存层

.vid2note/ 放 SQLite、搜索索引、临时片段与审批记录；不污染 Obsidian 内容树。

每次 Ingest 的事务边界

生成来源笔记 → 找相关 Wiki 页 → 产出 ChangeSet（新增、修改、引用、矛盾）→ 用户逐项批准 → 临时目录写入并校验 → 原子替换 → Git commit → 更新 index.md 与 log.md。

建议坚持

  • 稳定 source_id，不用文件名充当身份
  • 每条事实引用 source_id + 时间区间
  • 写 Wiki 必须经过 ChangeSet
  • 所有缓存都可重建

建议避免

  • 把 Markdown 正文塞进数据库
  • 一开始就强依赖向量数据库
  • 直接让 Agent 无边界修改整个 Vault
  • 预先生成所有视频片段，浪费磁盘
