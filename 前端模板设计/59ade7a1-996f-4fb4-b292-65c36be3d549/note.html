Transformer 自注意力机制详解

由 qwen-turbo 基于 412 段转录自动整理 · 视频时长 31:24 · 生成于 2026-06-15

一句话概要

自注意力（Self-Attention）让序列中每个位置在编码时，同时参考所有其他位置的信息，通过 Query-Key 的相似度决定「该关注谁」，再用 Value 做加权聚合。00:01:24

核心公式：缩放点积注意力

给定 Q（查询）、K（键）、V（值）三个矩阵：

Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V
为什么要除以 √d_k？00:02:41 当维度 d_k 较大时，点积结果的方差会随维度线性增长，使 softmax 进入梯度极小的饱和区。除以 √d_k 把方差拉回 1 附近，保持梯度友好。

多头注意力（Multi-Head）

把整套 QKV 计算并行做 h 组（论文中 h=8），每组用独立的投影矩阵，学到不同的「关注模式」：00:03:17

  • 有的头关注语法依赖（主谓一致）
  • 有的头关注长距离指代
  • 有的头几乎只看相邻 token

最后把 h 个头的输出拼接，再做一次线性映射回原维度。

三个易踩的坑

  1. Causal Mask：解码时未来位置不可见，加下三角 mask（-∞ 屏蔽）。00:04:02
  2. Padding Mask：批次内变长序列要 mask 掉 padding，否则会污染注意力分布。
  3. 数值稳定性：softmax 前务必减去最大值，避免上溢。

位置编码

注意力本身是置换不变的（把输入打乱结果一样），所以必须显式注入位置信息。原始论文用正余弦函数：00:18:30

PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

这样不同维度对应不同周期的波，模型能学到相对位置关系。

复杂度与直觉

自注意力的时间和空间复杂度都是 O(n²·d)（n 为序列长度）。这就是为什么长上下文很贵——每两个 token 都要算一次相似度。00:23:50

一句话记忆：Q 决定「我想找什么」，K 决定「我是什么」，相似度决定权重，V 是真正被聚合的内容。
